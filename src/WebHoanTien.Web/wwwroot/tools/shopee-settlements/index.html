CATSBack · SHOPEE

Tổng hợp bảng kê ngay trên điện thoại

Chạy trong tab Shopee trên Chrome Android, tải file JSON rồi tự import vào CatsBack. Không cần máy tính hay Local Helper.

1. Tạo dấu trang CatsBack

Bản v3 · Mã tải ngắn: dấu trang chỉ tải tool từ website CatsBack, không còn chứa toàn bộ mã tổng hợp. Thay URL dấu trang cũ bằng mã mới một lần; những lần sau tool được cập nhật từ website.

  1. Bấm Sao chép mã tải ngắn bên dưới.
  2. Trong menu ⋮ của Chrome, bấm ngôi sao để lưu trang này.
  3. Mở phần chỉnh sửa dấu trang: đặt tên CatsBack JSON, thay toàn bộ ô URL bằng mã vừa sao chép và lưu lại. URL phải bắt đầu bằng javascript:.

2. Tổng hợp và tải JSON

  1. Mở danh sách bảng kê Shopee và đăng nhập. Nếu cần, bật Trang web cho máy tính trong menu Chrome.
  2. Ngay tại tab Shopee, chạm thanh địa chỉ, gõ CatsBack JSON rồi chọn dấu trang cùng tên trong gợi ý. Chờ tool tải từ website và mở bảng điều khiển; nếu không tải được, tool sẽ báo lỗi.
  3. Đổi bộ lọc/kỳ hoặc chuyển trang danh sách để Shopee tải dữ liệu mới. Có thể thu gọn bảng CatsBack để thao tác. Không tải lại toàn bộ tab, vì thao tác đó sẽ tắt tool.
  4. Khi tool báo đã nhận danh sách, bấm Tổng hợp JSON. Giữ tab mở, màn hình sáng và không đổi bộ lọc trong lúc chạy.
  5. Bấm Tải file JSON. Về CatsBack → Affiliate → Import JSON đối soát, chọn file trong thư mục tải xuống.

Chỉ tổng hợp các bảng kê trong response danh sách vừa được Shopee tải. Muốn lấy kỳ/trang khác, đổi bộ lọc rồi tổng hợp một file mới. Lỗi đối soát sẽ dừng xuất file; không tạo báo cáo một phần.

Khi chưa thấy tool

Chọn đúng gợi ý dấu trang trong thanh địa chỉ. Sau mỗi lần tải lại trang Shopee, chạy dấu trang lại. Cách này cần kết nối được đến website CatsBack. Nếu báo không tải được tool, kiểm tra mạng và gửi lại thông báo; Shopee cũng có thể chặn mã tải từ website khác.

Việc thấy “CatsBack OK” chỉ xác nhận dấu trang chạy được, chưa xác nhận Shopee cho phép tải tool từ CatsBack.

Đã thấy “CatsBack OK” nhưng tool vẫn không hiện

Mở chỉnh sửa dấu trang CatsBack JSON, sao chép toàn bộ URL đã lưu rồi dán vào ô dưới. Mục này chỉ so sánh mã trên thiết bị, không chạy mã và không gửi lên server.

Nếu mã khớp nhưng bảng điều khiển vẫn không hiện, gửi lại thông báo lỗi hoặc ảnh màn hình ngay sau khi chạy dấu trang.

Website CatsBack cung cấp file mã tool; dữ liệu Shopee vẫn được đọc và tạo JSON ngay trong tab Shopee. Không gửi cookie Shopee hay bảng kê về website khi tổng hợp. Bạn tự chọn thời điểm import; dữ liệu import vẫn chờ admin duyệt.
