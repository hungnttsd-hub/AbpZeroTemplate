CATSBack · SHOPEE

Tổng hợp bảng kê ngay trên điện thoại

Chạy trong tab Shopee trên Chrome Android, tải file JSON rồi tự import vào CatsBack. Không cần máy tính hay Local Helper.

1. Tạo dấu trang CatsBack

  1. Bấm Sao chép mã dấu trang bên dưới.
  2. Trong menu ⋮ của Chrome, bấm ngôi sao để lưu trang này.
  3. Mở phần chỉnh sửa dấu trang: đặt tên CatsBack JSON, thay toàn bộ ô URL bằng mã vừa sao chép và lưu lại. URL phải bắt đầu bằng javascript:.

2. Tổng hợp và tải JSON

  1. Mở danh sách bảng kê Shopee và đăng nhập. Nếu cần, bật Trang web cho máy tính trong menu Chrome.
  2. Ngay tại tab Shopee, chạm thanh địa chỉ, gõ CatsBack JSON rồi chọn dấu trang cùng tên trong gợi ý. Bảng điều khiển CatsBack sẽ xuất hiện.
  3. Đổi bộ lọc/kỳ hoặc chuyển trang danh sách để Shopee tải dữ liệu mới. Có thể thu gọn bảng CatsBack để thao tác. Không tải lại toàn bộ tab, vì thao tác đó sẽ tắt tool.
  4. Khi tool báo đã nhận danh sách, bấm Tổng hợp JSON. Giữ tab mở, màn hình sáng và không đổi bộ lọc trong lúc chạy.
  5. Bấm Tải file JSON. Về CatsBack → Affiliate → Import JSON đối soát, chọn file trong thư mục tải xuống.

Chỉ tổng hợp các bảng kê trong response danh sách vừa được Shopee tải. Muốn lấy kỳ/trang khác, đổi bộ lọc rồi tổng hợp một file mới. Lỗi đối soát sẽ dừng xuất file; không tạo báo cáo một phần.

Khi chưa thấy tool

Kiểm tra dấu trang đã lưu đầy đủ mã và chọn đúng gợi ý dấu trang trong thanh địa chỉ. Sau mỗi lần tải lại trang Shopee, chạy dấu trang lại. Nếu trình duyệt hoặc chính sách trang chặn JavaScript dấu trang, tool không thể chạy trong tab đó.

Tool chỉ đọc dữ liệu bằng phiên Shopee hiện tại và tạo file trên máy. Không yêu cầu sao chép cookie hoặc nhập Client Secret. Bạn tự chọn thời điểm import; dữ liệu import vẫn chờ admin duyệt.
