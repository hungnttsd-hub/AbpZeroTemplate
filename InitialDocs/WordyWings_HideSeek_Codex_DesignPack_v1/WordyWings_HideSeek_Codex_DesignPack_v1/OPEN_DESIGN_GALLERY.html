02 - Implementation annotation plates

A01 / Screen hierarchy and safe interaction

WORLD: large scene, four neutral hiding spots. Keep the full scene below the quest header. / HUD: quest + audio replay, 3-star counter, pause. Tools sit at the bottom safe area. / INITIAL: no animal, scissors, tail, ear, shadow or species sound is visible. Source star count must be corrected to 3. / MASTER FRAME: 1600 x 900. See layout.json for component rectangles; do not stretch the source bitmap.

images/annotated/A01.png

A02 / Quest header: no image answer leak

Copy: Find a cat. Audio reads exactly the same quest. Keep sentence case. / Never add a cat thumbnail, silhouette, meow or answer-specific sparkle beside the instruction. / Replay button: 64 x 64 design units; at least 48 CSS px after scaling on a real device. / Target text is allowed. Discovering its visual meaning is the point of the level.

images/annotated/A02.png

A03 / Stars and scoring

Begin at 3 / 3. Only a wrong YES / NO answer loses one star. / No penalty for opening a distractor, missing a swipe, choosing another tool or taking time. / Clamp at zero. Continue with guided help; no negative scores and no forced restart. / One charge per reveal. Completing with 1 star displays and saves 1 star, not 3.

images/annotated/A03.png

A04 / Hiding layers and object visibility

This crop shows a REVEALED cat; it is NOT a valid starting background. / Runtime layers: empty background -> object (invisible) -> closed cover -> reveal VFX. / Switch the object visible only at reveal completion. Disable its input before that point. / Every spot uses the same idle motion distribution, independent of its occupant.

images/annotated/A04.png

A05 / Swipe Leaves interaction

Select leaves tool; drag the cover sideways. Accumulate signed displacement, not back-and-forth rubbing. / Threshold: 55% of cover width, capped at 96 design units. Release below threshold springs back. / 0-180 ms: cover follows gesture. 180-520 ms: leaves part. 520-820 ms: neutral reveal and quiz. / Tap-to-open alternative is available. Wrong gesture is never a learning error.

images/annotated/A05.png

A06 / Throw Net interaction

Select net; tap a compatible bush. Use a deterministic arc to the chosen spot. / 0-360 ms: cast. 360-620 ms: net catches foliage. 620-900 ms: lift and dissolve net. / Reveal the animal AFTER the net disappears. Never show an animal bound in the net. / Lock other spots during the short reveal animation; then open the quiz.

images/annotated/A06.png

A07 / Blast Berry interaction

Select foam berry; tap a rock cover. Aim preview is neutral and not tied to the answer. / 0-280 ms: berry arc. 280-560 ms: soft puff and split rock. 560-1000 ms: debris fades, reveal. / No realistic explosion, sharp shards, injury or damage to a visible object or animal. / Keep this effect deterministic with tweens. Full destruction physics is unnecessary.

images/annotated/A07.png

A08 / Question panel and input lock

Question: Is this a cat? Show ONLY the revealed object portrait beside it. / Before an answer: no object name, green outline, success audio or correctness hint. / YES and NO are equal-sized controls. Remove the X while the question is unanswered. / While the panel is active, the world and tool tray cannot receive input.

images/annotated/A08.png

A09 / Correct NO on a distractor

Reveal: dog. Quest: Find a cat. Child chooses NO. / Feedback: No. It is a dog. Keep all current stars. / Mark this spot searched, remove its quiz trigger and return to searching. / This NEVER completes the level. Momo encourages the child to find the cat.

images/annotated/A09.png

A10 / Correct YES on the target

Reveal: cat. Quest: Find a cat. Child chooses YES. / Feedback: Yes! It is a cat. Set completion state exactly once. / Play greeting and celebration; retain remaining stars. Offer Next and Play again. / Never reuse the source storyboard caption saying to continue searching after this answer.

images/annotated/A10.png

A11 / Wrong answer and assisted retry

Wrong YES on dog: lose one star; show No. It is a dog.; return to search. / Wrong NO on cat: lose one star; explain Yes. It is a cat.; offer an assisted YES retry. / Repeated NO on that same revealed cat does not drain more stars. No extra learning credit. / Use atomic processing, revealId and answerEventId to reject duplicate taps and retries.

images/annotated/A11.png

A12 / Success pose and payoff

Target + YES is the only success gate. Searching all spots is not itself a win. / Momo and the found animal meet. Gentle sparkles, a brief voice cue, then stable result UI. / No intense flash or unavoidable shaking. Reduced motion uses fades. / Stars shown in the reference are illustrative; runtime must use the current session value.

images/annotated/A12.png

A13 / Tool tray and mobile ergonomics

Desktop: three tools centred at the bottom. Highlight the selected TOOL, never the hidden answer. / Mobile landscape: compact floating tray, minimum 48 CSS px per control and safe-area offsets. / Tap tool -> tap spot is sufficient. Drag precision is optional. / Unsupported tool on a spot: a neutral bounce and tool hint; no penalty.

images/annotated/A13.png

A14 / Objects, plural grammar and feedback

Level one distractors: dog, tiger and scissors. All use the same question: Is this a cat? / If the target is scissors, use Find the scissors. and Are these scissors? / Scissors are one vocabulary entity despite plural grammar. Store complete authored sentences. / Do not generate articles or plural questions with simple string concatenation.
