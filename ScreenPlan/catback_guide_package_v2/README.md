# CatBack Guide UI Package — Full Guide + Video Detail

Gói dùng để triển khai đầy đủ cụm **Hướng dẫn mobile CatBack**.

Bao gồm:
- chỉnh sửa Home để thêm link `Xem hướng dẫn ›`
- trang **Hướng dẫn** mobile
- 3 màn **Chi tiết video**:
  - Cài đặt / thêm lối tắt
  - Tạo link hoàn tiền
  - Đăng ký tài khoản

## Bắt đầu
Đọc theo thứ tự:
1. `spec.md`
2. `CODEX_INSTRUCTIONS.md`
3. thư mục `reference/`
4. thư mục `blueprint/`
5. thư mục `svg/`
6. `design-tokens.json`

## Nội dung chính trong ZIP
- `spec.md`
- `CODEX_INSTRUCTIONS.md`
- `design-tokens.json`
- `blueprint/*.svg`
- `svg/*.svg`
- `reference/*.png`

Không cần bundle font riêng. Ưu tiên logo/mascot/icon đang có trong source CatBack.
