# Catback Notification Codex Package

Gói này dành riêng cho tính năng **Quản lý thông báo** của Catback để Codex/dev triển khai đúng giao diện đã duyệt.

## Bắt đầu
1. Đọc `docs/spec.md`
2. Đọc `docs/notification-notes.md`
3. Đọc `docs/abp-mvc-notes.md`
4. Nếu muốn copy prompt cho Codex, dùng `docs/codex-prompt.md`
5. Mở toàn bộ ảnh trong `references/notification/`
6. Mở toàn bộ blueprint trong `blueprints/`
