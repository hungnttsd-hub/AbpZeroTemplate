Thu muc tai file

Chrome Extension chỉ được chọn đường dẫn tương đối bên trong thư mục Downloads của Chrome. Với Chrome Downloads = C:\Users\HUNGNT\Downloads và giá trị CatsBack, file sẽ vào đúng C:\Users\HUNGNT\Downloads\CatsBack.
Tối thiểu 60 phút.
Nếu popup/tab mới bị Chrome chặn, tool sẽ fallback sang trang Export Management đã mở để tiếp tục kiểm tra file.
Mặc định 10000. Đặt 0 nếu không muốn extension chủ động reload.
v0.6.3: mặc định không dùng class Shopee làm identity. Nút Export được chấm điểm theo exact text Xuất dữ liệu, element tương tác native/ARIA, visibility và trạng thái enabled. Nếu có nhiều candidate ngang điểm, tool dừng với EXPORT_BUTTON_AMBIGUOUS thay vì click nhầm. Ở Export Management, tool nhận diện report bằng AffiliateCommissionReport_YYYYMMDDHHmm.csv và URL download có task_id; icon/class chỉ còn phục vụ debug.

CatsBack Automation API

Endpoint đã cấu hình sẵn theo tài liệu API. Bạn chỉ cần nhập Client ID và Client Secret. Helper không lưu access token dài hạn; token ngắn hạn được lấy tự động và giữ trong RAM.

Đang kiểm tra Local Helper...
Nên khớp với thư mục tải của extension. Nếu bạn đang dùng C:\Users\HUNGNT\Downloads\CatsBack thì để Thư mục con trong Chrome Downloads = CatsBack.
Chưa kiểm tra secret đã lưu.
Theo API hiện tại: report=<file CSV/TXT>.
Flow API: Helper POST JSON client_id/client_secret để lấy token → cache token đến gần hạn → POST multipart/form-data sang endpoint import với Authorization: Bearer .... Nếu import trả 401, Helper tự xin token mới một lần rồi thử lại.
