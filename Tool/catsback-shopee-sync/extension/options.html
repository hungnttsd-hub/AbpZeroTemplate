CatsBack Automation API

Endpoint đã cấu hình sẵn theo tài liệu API. Bạn chỉ cần nhập Client ID và Client Secret. Helper không lưu access token dài hạn; token ngắn hạn được lấy tự động và giữ trong RAM.

Đang kiểm tra Local Helper...
Chưa kiểm tra secret đã lưu.
Theo API hiện tại: report=<file CSV/TXT>.
Flow API: Helper POST JSON client_id/client_secret để lấy token → cache token đến gần hạn → POST multipart/form-data sang endpoint import với Authorization: Bearer .... Nếu import trả 401, Helper tự xin token mới một lần rồi thử lại.
